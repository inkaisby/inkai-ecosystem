# Roadmap Pengembangan Detail INKAI

Dokumen ini melacak fitur-fitur tambahan yang sedang dikerjakan secara bertahap untuk melengkapi ekosistem aplikasi INKAI.

## Status Pengembangan:

- [x] **Tahap 1: Notification Center (Pusat Informasi)**
    - Wireframe halaman notifikasi di Aplikasi Mobile.
    - Wireframe manajemen broadcast di Web Admin.
- [x] **Tahap 2: Support & Helpdesk**
    - Halaman FAQ dan Pusat Bantuan di App.
    - Sistem ticketing sederhana untuk Admin.
- [x] **Tahap 3: Manajemen Event Detail (Admin Side)**
    - Form pembuatan event (Kategori, Kuota, Banner).
    - Dashboard monitoring pendaftar per kategori.
- [x] **Tahap 4: Admin & User Management**
    - Manajemen role dan akses pengurus.
    - Invite system untuk admin baru.
- [x] **Tahap 5: Audit Logs & Keamanan**
    - Rekaman aktivitas admin.
    - Halaman pengaturan keamanan akun user.
- [x] **Tahap 6: Landing Page & Public Info**
    - Website publik (sebelum login).
    - Direktori Dojo publik.
- [x] **Tahap 7: Manajemen Lisensi Pelatih & Wasit**
    - Profil khusus fungsional (Lisensi Wasit/Pelatih).
    - Monitoring masa berlaku lisensi (Admin).
- [x] **Tahap 8: INKAI Store (Inventori)**
    - Katalog perlengkapan resmi (Karategi, Sabuk, dll).
    - Manajemen stok dan pesanan.
- [x] **Tahap 9: Public Verification Tool**
    - Fitur cek keaslian anggota (NIA Check) di Landing Page.
- [x] **Tahap 10: Digital Library & Advanced Analytics**
    - Library video teknik (Kata/Kumite) di App.
    - Dashboard heatmap & tren pertumbuhan nasional.
